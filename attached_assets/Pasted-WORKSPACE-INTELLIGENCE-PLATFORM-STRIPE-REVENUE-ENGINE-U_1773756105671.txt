PART 5 — PAYMENT LINK ENGINE

Capabilities:

• create Stripe product/price dynamically from quote
• create Stripe payment link
• optionally create checkout session
• support deposit or full payment
• store generated link in database
• attach link to quote and opportunity

Rules:

• one quote may have multiple payment links over time
• only latest active link should be primary

• stale links must be marked superseded

PART 7 — WEBHOOK ENGINE

• update quote / opportunity / revenue state
• create audit log entry
• notify Command Centre widgets

• allow live payment flow
• allow real invoices
