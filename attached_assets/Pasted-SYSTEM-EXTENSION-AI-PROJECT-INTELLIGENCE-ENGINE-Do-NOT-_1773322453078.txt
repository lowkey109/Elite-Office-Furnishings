SYSTEM EXTENSION — AI PROJECT INTELLIGENCE ENGINE

Do NOT remove existing functionality.
Do NOT rebuild the platform.
Do NOT overwrite existing prompts.

This upgrade adds a project intelligence system so the AI can learn from every workspace project and improve future recommendations.

The Corporate Desk AI must operate as a commercial workspace intelligence platform.

------------------------------------------------
OBJECTIVE
------------------------------------------------

Create a project intelligence engine that allows the AI to learn from every office fit-out.

The AI must be able to analyze past projects and use that knowledge to predict:

• project cost
• project margin
• supplier selection
• furniture packages
• layout efficiency
• installation complexity

The system should improve recommendations as more projects are completed.

------------------------------------------------

------------------------------------------------

Create a structured project database.

client_company
location

staff_count
industry_type

project_budget

furniture_package

margin
installation_complexity
delivery_lead_time
client_feedback

Store projects permanently so they can be analyzed by the AI.

variable
