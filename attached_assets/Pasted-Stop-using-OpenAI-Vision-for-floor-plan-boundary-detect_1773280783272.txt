Stop using OpenAI Vision for floor plan boundary detection.

This must be replaced with a deterministic computer vision parser.

OpenAI Vision is unreliable for production geometry detection.

------------------------------------------------

REQUIRED CHANGES

Remove the OpenAI Vision detection step entirely.

Replace it with proper boundary detection using image processing.

Detection pipeline must be:

1. Convert image to grayscale
2. Apply adaptive threshold
3. Run Canny edge detection
4. Detect contours
5. Identify the largest external contour
6. Approximate the contour to a polygon
7. Normalize coordinates to 0-1 space

Use this polygon as the real floor boundary.

------------------------------------------------

INTERIOR WALL DETECTION

Add Hough Line detection to identify internal walls where possible.

These lines should be stored separately from the outer boundary.

------------------------------------------------

REMOVE RECTANGLE FALLBACK

The system must never default to a generic rectangle if a boundary can be detected.

Fallback logic should be:

1. use detected outer contour
2. if contour detection fails, use convex hull of edges
3. only if the image is completely unreadable may a rectangle be used

All fallbacks must be logged.
