Purpose

	•	Active Strategy

2. Live Decision Feed (PRIMARY FOCUS)

Create a vertical scrolling feed (latest first).

	•	Timestamp

	•	Confidence (as % + progress bar)
	•	Thesis (short sentence)
	•	Volume Ratio
	•	Regime
	•	Hour
	•	Reason Code

	•	Smooth auto-scroll
	•	Highlight new entries briefly
	•	Max 50 items in memory

3. Expandable Decision Detail

Each decision row must be clickable.

On expand, show:
	•	Expected Move
	•	Expected Cost
	•	Invalidation Rule

	•	Data Quality Score
