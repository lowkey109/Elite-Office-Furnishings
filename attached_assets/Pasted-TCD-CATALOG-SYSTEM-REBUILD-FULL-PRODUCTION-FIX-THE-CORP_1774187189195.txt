SECTION 5 — DEDUPLICATION RULES
==================================================

Implement strong deduplication.

A product must not be inserted more than once if any of these collide strongly:
- same sku
- same sku + same image
- same canonical name + same image
- same slug + same image

If exact duplicates exist:
- keep best valid record only
- discard the rest

If multiple variants exist intentionally:
- keep as separate only if SKU is genuinely distinct and image is valid
