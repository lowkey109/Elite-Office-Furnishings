**STAGE 1 — GLOBAL INTELLIGENCE GRAPH (FULL IMPLEMENTATION)**

**1.1 GRAPH DATA MODEL**  
Use existing PostgreSQL database.  

Create table:  
`graph_edges`  

Fields:  
- `id` (uuid primary key)  
- `from_entity_type` (string)  
- `from_entity_id` (string)  
- `to_entity_type` (string)  
- `to_entity_id` (string)  
- `relationship_type` (string)  
- `weight` (float default 1)  
- `confidence_score` (float 0–100)  
- `metadata_json` (jsonb)  
- `created_at` (timestamp)  

**MANDATORY INDEXES**  
- `idx_graph_from`  
- `idx_graph_to`  
- `idx_graph_relationship`  
- `idx_graph_composite` (from_entity_type, from_entity_id)  
- `idx_graph_reverse` (to_entity_type, to_entity_id)  

**UNIQUE CONSTRAINT (DEDUP)**  
`(from_entity_type, from_entity_id, to_entity_type, to_entity_id, relationship_type)`

**RELATIONSHIP TYPES** (must support all)  
COMPANY_OCCUPIES_BUILDING • COMPANY_HAS_CONTACT • COMPANY_HAS_SIGNAL • COMPANY_HAS_OPPORTUNITY • COMPANY_INDUSTRY • COMPANY_LINKED_TO_PARTNER • BUILDING_IN_SUBURB • BUILDING_HAS_TENANT • TENANT_INDUSTRY_CLUSTER • COMPANY_SUBSIDIARY • COMPANY_PARENT • CLUSTER_MEMBER  

**1.2 GRAPH WRITE ENGINE**  
Create `GraphWriteService` with:  
`upsertEdge({ fromEntityType, fromEntityId, toEntityType, toEntityId, relationshipType, weight, confidenceScore, metadata })`  

Must be fully idempotent, prevent duplicates, and update existing edges on conflict.

**1.3 EVENT-DRIVEN GRAPH ENRICHMENT**  
Hook into existing system events (real-time):  
- SIGNAL CREATED → COMPANY_HAS_SIGNAL  
- TENANT CREATED → BUILDING_HAS_TENANT + COMPANY_OCCUPIES_BUILDING  
- OPPORTUNITY CREATED → COMPANY_HAS_OPPORTUNITY  
- CONTACT CREATED → COMPANY_HAS_CONTACT  
- PARTNER LINKED → COMPANY_LINKED_TO_PARTNER  
- LEASE UPDATED → update COMPANY_OCCUPIES_BUILDING confidence  
- INDUSTRY ASSIGNED → COMPANY_INDUSTRY  

**1.4 GRAPH QUERY ENGINE**  
Create `GraphService` with:  
- `getNeighbors(entityType, entityId, depth=1)`  
- `getSecondDegreeConnections(entityType, entityId)`  
- `getCompanyNetwork(companyId)`  
- `getConnectedOpportunities(companyId)`  
- `getCompaniesInSameBuilding(buildingId)`  
- `getCompaniesInSameSuburb(suburb)`  
- `getCompaniesInSameIndustry(industry)`  
- `getGraphPaths(entityType, entityId, maxDepth)`  

**1.5 CLUSTER ENGINE** (job-based)

`clusters` (id, type, region, cluster_score, entity_ids jsonb, created_at)  

Identify: growth clusters, relocation clusters, high-risk buildings, industry density clusters.  
Automatically create CLUSTER_MEMBER edges.

**1.7 OPPORTUNITY ENGINE UPGRADE**

clusterScoreWeight • networkSignalWeight • buildingInstabilityWeight • industryDensityWeight
