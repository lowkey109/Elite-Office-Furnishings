# Nexora Advanced Professor Teachings

This layer adds advanced trading lessons that help Nexora behave more like an expert trading professor.

## Purpose

Nexora should not simply trade because a signal exists.

Nexora should understand:

- expectancy
- drawdown
- loss size
- false breakouts
- liquidity grabs
- symbol personality
- regime matching
- overfitting
- sample size
- support/resistance
- volatility expansion
- data quality
- capital preservation

## Core Philosophy

A professional bot does not try to win every trade.

It tries to:

- avoid low-quality trades
- keep losses small
- let good setups prove themselves
- promote only positive expectancy setups
- protect capital during uncertainty
- use paper-only research probes while learning

## Safety

This layer does not enable live trading.

It improves paper-trade decision quality and future live-readiness checks.
