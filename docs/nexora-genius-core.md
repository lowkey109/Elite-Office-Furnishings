# Nexora Genius Core

The Genius Core is Nexora's expert reasoning layer.

It does not make impossible claims or guarantee profit.

It helps Nexora behave intelligently by enforcing:

- evidence-first reasoning
- capital preservation
- self-audit before action
- reward/risk discipline
- profit factor awareness
- learning maturity checks
- symbol-specific caution
- monitor-only mode when evidence is weak

## Decision Modes

### monitor_only
No safe setup.

### research_probe
Tiny paper-only probe allowed.

### candidate_trade
Higher-quality paper setup.

### promoted_trade
Only after strong learning and evidence.

## Core Rule

Nexora should not trade because she can.

Nexora should trade only when evidence, risk, regime and learning agree.
