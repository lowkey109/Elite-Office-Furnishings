## Required production security rules

- Every dangerous admin action must require server-side admin authentication.
- Every long-running job must have a lock to prevent duplicate concurrent runs.
- Every send/release/push/delete action must write an audit record.
- Customer/public endpoints must not be protected by admin auth, but must validate input and file type.
- Railway deployment is intentionally not run in this stage.
